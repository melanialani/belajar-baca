# Ayo Baca! (belajar-baca)

Reading-practice web app for Indonesian kindergarten kids. Background, deploy notes and history: [docs/project-notes.md](docs/project-notes.md).

## Stack & structure
- Static files, no build step, no package manager. Classic `<script>` files sharing globals (no modules).
- `index.html` (markup) → CSS per feature, in order: `css/base, home, learn, game, parent, reading-games, writing, math, science, experiments, safety, toddler.css` (put new rules in the file of their feature; later files win ties). Plain `<script src>` files in order: `js/emoji-index.js, helpers.js, tts.js, words.js, learn.js, parent.js, profiles.js, ui.js, engine.js, reading-games.js, math.js, math-learn.js, parade.js, phonics.js, count-games.js, memory.js, number-games.js, data/tulis.js, writing.js, data/cerita.js, data/dongeng-*.js, data/gambar-cerita.js, stories.js, math-sd.js, english.js, voice.js, placement.js, worksheet.js, science-data.js, data/sains-*.js, science.js, data/fakta-*.js, facts.js, shapes.js, data/eksperimen*.js, experiments.js, data/jaga-diri.js, data/perasaan.js, data/kuis-tambahan.js, safety.js, daily.js, toddler.js, main.js`. `sw.js` (service worker, offline) + `manifest.webmanifest` + `assets/icons/` make it an installable app.
- Navigation: Home → Belajar (`#hubLearn`) / Main (`#hubPlay`) / Jaga Diri (`#jagadiri`: safety cards `JD_STAGES` + games `JD_GAMES`, content `js/data/jaga-diri.js`, feelings `js/data/perasaan.js`) / Stiker, plus Latihan Hari Ini and Si Kecil (`#sikecil`, toddler play without levels, `js/toddler.js`); each hub opens Baca, Hitung, Sains, English (`EN_STAGES`/`ENG_GAMES`, `js/english.js`; Belajar also Eksperimen). Belajar Baca also has Menulis (tracing, `js/writing.js` + strokes in `js/data/tulis.js`) and Buku Cerita (group card of the short stories `STORIES`, `js/data/cerita.js`, `js/stories.js`). Home also has Buku Cerita (`#cerita`, `buildTales()`): tabs Putri / Cerita Dunia / Cerita Rakyat / Cerita Pendek, every story in Indonesian and English (`SET.slang`, ID/EN switch on the menu and in the reader `#llang`). Tales: `TALES` in `js/data/dongeng-*.js` (`{id, grp, e, t:[id, en], src, pages:[[pictures, id text, en text, optional image]]}`), public-domain versions told in our own words (no Disney-only plots, characters or pictures); short stories have `te` + an English third page element. Pictures live in `assets/stories/` but are switched off (`STORY_PICS=false` in `js/stories.js`, 2026-10-30: too scary for small children), so every story shows emoji, listed in `js/data/gambar-cerita.js` (generated by `tools/story_images.py build`; only free licences, credits shown on the cover and in Pengaturan); SD counting (×, :, place value, clock, rupiah, fractions) is `js/math-sd.js`. Learn lists: `STAGES`, `MATH_STAGES` (reuses the learn viewer via `item.render`), `SCI_STAGES`; game lists: `GAMES`, `MATH_GAMES`, `SCI_GAMES` (same level engine). Sains = anything that is neither reading nor counting (colors, shapes, patterns, animals, science topics; content in `js/science-data.js` and, for categories split into smaller cards (`groups` → card with `sub`, opened in `#sciGroup`), `js/data/sains-*.js`). Tahukah Kamu? facts: `FACT_CATS` in `js/data/fakta-*.js`, built by `js/facts.js`. Belajar also has Eksperimen (`EXP_STAGES`, content `js/data/eksperimen*.js`). Content rules (numbers as words, no symbols, safe experiments): see `docs/project-notes.md`. Buttons navigate with `data-go` (+ `data-say` for the spoken name). Card order (easy → hard) is set only in `main.js` (`byIds`); add new ids there; counting core (`numW` 0–100, visuals, level ladders `NUMR`/`opPair`) lives in `js/math.js`, its learn stages in `js/math-learn.js`, shapes & patterns in `js/shapes.js`. Counting games pick difficulty per level (`D.L`, 1–25), not only per band. Show amounts with `qtyEl()` (objects ≤10, ten frames ≤20, base-ten blocks beyond). Extra game files push into `GAMES`/`MATH_GAMES`; `ALLGAMES` is built in `main.js` and is what anything summing stars/games uses. Reuse `parade()` (moving answers), `memoryGame()` and `okBtn()` instead of new variants. Numbers are spoken via `numW()` (words), never raw digits.
- Emoji: one SVG per emoji in `assets/emoji/<hex code points joined by ->.svg`; `EMO` (`js/emoji-index.js`) is the Set of available keys. New emoji: export with `tools/emoji_tool.py` (Fluent Emoji from `@iconify-json/fluent-emoji`), then add the keys to `EMO`. Always render emoji via `ico()`/`emojify()` (lazy `<img>` with text fallback via `emoFail`); use `preloadEmo()` for icons revealed later. Don't print the SVG files.
- Look (2026-10-29 redesign): colours only via the tokens in `css/base.css` (`--bg`, `--card`, `--sf2`, `--line`, `--ink`, `--ink2`, `--pri`, subject colours `--pink` … `--coral`, `--sh` soft shadow, `--press` inset press edge, `--hl` highlight); light by default, dark via `prefers-color-scheme` or `SET.theme` (`data-theme` on `<html>`). Tiles and cards use a light tint of their colour `color-mix(in srgb,var(--c) var(--tint),var(--card))` with dark text; answer buttons stay solid colours with white text. No solid dark drop shadows (`0 6px 0 #…`), no hard-coded white backgrounds (they break dark mode).
- Pengaturan is a full page (`#parentov`, back arrow), opened by holding the ⚙️ button on Home 3 s. Mode Didampingi (`SET.comp`, shared, chosen in "Siapa yang main?" by holding 2 s, or in Pengaturan): `body.comp` shows the ⚙️ buttons (`.gear`), game name + written instruction (`#ginst`, from `g.ins`), hub descriptions and today's summary (`todayAdd`, per child). Subtitles (`SET.sub` auto/on/off, `js/ui.js`): `TTS.onCap` shows every spoken part in `#subt`; screens leave room for it (`body.subs`); during an open game question words other than `g.ins`/feedback are covered (tap to read) so the child cannot read the answer. Voice guide: `openGuide()` (`VG` steps per brand, `VFAQ`).
- State lives in `localStorage` via `store` (prefix `ayobaca2:`). Child profiles (`PROFILES`, `PROF`, `js/profiles.js`): profile 1 uses the plain keys, profile n `ayobaca2:p<n>:`; `profiles`, `prof` and `set` are shared (see `GLOBALK`). Settings in `SET`: shared ones in `set`, per child (`case`, `tod` = Mode Balita) in `pset`; save with `saveSet()`. Parent voice recordings live in IndexedDB `ayobaca-voice` (`js/voice.js`) and are played by `TTS.say` instead of the voice for that text.

## Branch & deploy
- Work on branch `claude`; merge into `main` only when the user approves. For later changes switch back to `claude` (bring it up to date with `main` first).
- Cache busting: CSS/JS links in `index.html` carry `?v=YYYY-MM-DD`. Bump it on every release that changes CSS/JS (GitHub Pages caches ~10 min; this keeps a new `index.html` from mixing with old JS), and bump `VER` in `sw.js` the same way (the service worker serves cached files first; a new `VER` drops the old cache). Emoji SVGs need no version.
- Public URL: https://melanialani.github.io/belajar-baca/ (GitHub Pages, repo `melanialani/belajar-baca`). Only what is pushed to `main` goes live.

## Rules
- UI text shown to kids/parents is Indonesian (app language); code, comments, identifiers, commits stay English.
- Displayed words/syllables/letters must go through the case helpers (`caseWord`, `casePart`, `caseUnit`) so the parent "Bentuk huruf" setting applies. TTS always gets the raw lowercase data.
- New parent settings: add a `.setrow` in the right `.grp` group of `#parentov`, default in `SET`, persist with `store.set('set',SET)`; reuse the `.seg`/`.tog` patterns.
- Game feedback (all games, via the shared `api.ok()`/`api.bad()` in `nextQ`; new games must use them, no own timers/feedback):
  - Correct: confetti + big random `PRAISE` text + its voice, then go to the next question right after (≈1 s), no long pause.
  - Wrong: big X + random `OOPS` text + its voice, one heart lost, then the right answer is shown and spoken ("Yang benar …") and a NEW question replaces it (the wrong one does not count; children must not be able to tap every option until one fits). Every game marks its right answer: `optsEl(list,render,onPick,cls,isOk)` / `numBtns` set `data-ok`, `api.ans(say, showFn)` gives the spoken answer and how to show it, `api.solve(fn)` lets the automated checks finish multi-step questions. Exceptions on purpose (`D.keep`): Kartu Memori, Baca Keras, Tulis Huruf.
  - Missed questions come back in later (harder) levels until answered right twice: words via `MISS`, other games via the redo list (`redoAdd`/`redoPick`/`redoDone` in `engine.js`, keys set as `D.key` by the pickers `takeNum`, `opQ`, `sciTake`, …).
  - Mode Balita (`SET.tod`): no hearts, no game over, levels 1–25, at most 3 choices. Tes Awal (`G.g.test`, `js/placement.js`): a wrong answer just moves on.
  - `HEARTS` = 5 per level; 0 hearts → `GAMEOVER` text + voice, back to that game's level list, no stars. Stars: 0 wrong 3⭐, 1–2 2⭐, 3–4 1⭐. The level grid shows the stars of the last try (`lvl:`), totals and stickers use the best (`lv:`).
- Levels: 100 per game in pages of 25 (`MAXL`, `PAGEL`). `makeD(L)`: `b` = band 0–4 (levels 1–25, keep them unchanged), `x` = 0 up to 25, then 1–15 for levels 26–100; `qn` questions (5, 6 from 51, 7 from 76). Use `bv(D,[five values for bands 0–4],[values for x=1…])` and `optN(D)` instead of indexing arrays by `D.b`. Word tiers 14–18 (`MAXT`) are for levels 26+; numbers go up to 9 999 (`numW` up to 999 999). 300 stickers (`stkNeed` unchanged for the first 100).
  - Every word question must let the child hear the word (🔊 button and/or auto-say), except games where the sound is the answer (Tebak Nama Benda, Puzzle Bacaan Benda).
  - Feedback phrases are written in normal case (TTS-friendly) and shown uppercase via CSS.
- Timers that must survive screen-off (break countdown) use real clock time (`Date.now()` end time), never tick counting.
- Verify: `node --check js/*.js js/data/*.js sw.js`; test in the browser via the local static server on port **4006** (`.claude/launch.json`, `python -m http.server 4006`). Automated play-through: answer via `[data-ok]` or `G.solve()` for every game at levels 1, 25, 26, 50, 75, 100 (see docs/project-notes.md).
